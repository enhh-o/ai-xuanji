### 2026-09-07 总判与大运占位修正

- 三领域总判不再用固定的“应该如何分析”段落作为结论。按实际透藏、同干根气、六冲受扰及领域组合分支；建议跟随分支。相似结构仍可能得到相同总结，不随机换词制造个性化。
- 大运撤销固定“稳进”，改为支持增加、制耗增加、变动明显、作用交织、条件待辨。由本运天干十神、同干根、运支本气、与原局六冲／五合条件生成，并显示具体依据。颜色仅区分作用类型，不表示吉凶。
- 支持增加不能直接等于进取，制耗增加不能直接等于坏运；针对当前原局强弱给出条件性解释，不声称已完成六维用神裁决。根气受冲不等于拔根。
- 这一轮是针对总判模板和大运占位的修复，不是完整本地分析方案交付。当前综合复核按钮仍调用模型；完整格局、调候、用神及流年联合裁决尚未全部实现。紫微仍单列本命资料补充，不冒称已经完成跨体系裁决。
- 新增组合正反例和同一命盘不同运测试。人工抽取八组出生日期进行程序输出检查，不将这些输入称为真实命例或预测验证。测试只验证分支行为，不证明预测准确率。

出生资料 → 本地历法排盘 → 结构登记与常规扶抑初读 → 用户选择全盘复核 → 后端模型 → 本次命盘的复核结果与聊天。

- 四柱、藏干、十神、起运仍由 lunar-javascript 计算，不让语言模型心算重排。
- 初读区分透干与暗藏、同干根气、本中余气及逢冲受扰。逢冲不自动等于拔根。
- 程序候选五行不作为最终喜用神；尚未完成格局、调候和制化裁决时，不据五行命中自动判好大运。
- 全盘复核通过 `prompts/mingli-agent.md` 约定六个部分：总评、原局、格局取用、性格及三个领域、岁运窗口、行动建议和修订依据。这是模型任务契约，不是已验证的专家系统，也不代表全部参考库或古籍已导入。
- 紫微不可用时为空状态，不使用示例数据。三方、对宫只是结构关系，不分别等同于有利、不利。未计算紫微动态盘时不借本命四化冒充动态四化。

## 年份与时间边界

- 大运保存起止时间，当前运按左闭右开时间区间判断；未起运、超范围返回空。
- 当前时刻比对采用东八区的项目口径；城市经度及均时差校正仍为近似，不支持全球时区与历史夏令时精确还原。节气临界出生必须额外复核。
- 年度窗口从原局、大运和流年的具体关系筛选，不按信号条数打分、不固定选两步运。默认未来十年，可切换全部范围。
- 婚恋窗口要求运层主题、流年伴侣星及根气/合身线索和日支引动。仅透星或仅宫动不作为婚期。根气受损、争合等仍须在复核中辨明。
- 成人主题只在该公历年全年已满十八岁后显示，因此十八岁生日所在年不会自动标记。交运年暂不自动标记重点窗口，避免粗略年度归运造成错误；可问询具体日期另核。
- 所谓“窗口”是传统理论下的待验证线索，不是必然事件或科学概率；没有显示不等于人生没有变化。

## 问询与安全

- 普通问询发送当前与次年；未来三年发送三年；全盘/十年问题发送当前到十年后。问题明确写出的四位年份也会加入。更远问题需给具体年份。
- 完整大运起止、十二宫、藏干等仍保留。交运年份提供两步运，要求按日期区分。
- 命盘资料作为用户数据消息传入，而不是拼入系统角色。四柱校验长度、干支及阴阳配对；这不能证明用户填写的出生资料真实，也不能完全消除提示注入。
- 请求体最多 64 KiB，包括没有 Content-Length 的分块请求；模型最大生成额度 4096 token，服务端等待上限 60 秒。
- Cloudflare 配置增加 `AI_RATE_LIMITER`，每个来源 IP 每分钟 6 次；缺少线上绑定则关闭收费接口。本地另有限速，进程内每 IP 同时最多两个请求。
- 此限流不是全账户硬费用封顶，也不是严格的全球并发上限。公开推广前应在模型供应商控制台设置余额/额度限制，并考虑邀请访问或更严格的身份保护。
- 日志只记录请求编号、状态和耗时，不记录问题、出生资料、模型回答或密钥。换盘取消旧请求并忽略迟到响应；历史失败提示不再作为命理对话发送。
- 限流配置依据：[Cloudflare Rate Limiting](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)。
