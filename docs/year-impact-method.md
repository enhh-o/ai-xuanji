# 年份影响与力量条件（2026-09-12）

本轮从只列合冲生克改为：本命取用 → 大运及流年天干根气/月令/受制条件 → 触发宫位与十神主题 → 可能情境与观察事项。年份筛选仍沿用已有岁运窗口，不凭新增文案制造年份。

力量条件是项目中的定性规则，未以事件样本校准，不是量化预测：同类或生扶月令、有未受冲本气根且未识别制约时为“支撑较强”；有未受冲根为“有根支撑”；受冲根、争合或有透根克制者时为“作用受扰”；无上述支撑为“支撑有限”。受扰不等于失效，根气记录仍保留。根的本中余气、柱位以及月令条件直接展示；根数只作可核对计数，不合成能量分数。四柱距离、墓库与复杂合化尚未有完整强度裁决，不宣称已经完成数值量化。

影响情境按年度十神、既有本命喜忌、宫位引动、岁运冲合区分。事业落在职责考核或项目交付；财星可对应收支安排；印星对应学习资格及支持资源；关系区分共同承诺与安排调整。未成年不套成人职业婚恋。情境是解释假设，不能据此确定职业、婚姻状态或事件已经发生。
