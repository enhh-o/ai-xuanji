# 本地综合解读：本轮覆盖与限制

版本：local-2026-09-07。已接入本地页面，未推送或部署。

## 当前实际流程

历法引擎 → 四柱透藏与根气事实 → 旺衰与取格 → 配合及受阻条件 → 调候参考 → 六维取用 → 大运新增作用 → 立春流年和交运分段 → 四领域报告。

综合复核使用浏览器内规则，不调用模型。性格、事业、财富、感情卡片和喜忌、大运窗口消费同一报告。聊天仍须用户明确发送才调用模型，并携带本地结论供复核，不覆写规则报告。姓名和聊天内容不参与基础判断。

## 已实现且有行为测试

- 每柱天干、各藏干分开登记十神；同干根与同五行异阴阳支持分开。受冲保留根，不能先删根再判从。
- 月令本气透出优先，其他透出记兼格；建禄与阳干羊刃分开。旺衰采用定性条件，不用百分比。
- 财官印流通、食神制杀、杀印相生、官印相生、伤官佩印、羊刃驾杀、食神生财、伤官生财的条件检查。透干、有根、争合、明显阻断分别保留；“同见”不冒充已具备配合。
- 偏印制食神、伤官与正官相碍、财印相碍、比劫与财争用、官杀并透、七杀缺少显性制化、财星有根而承接待辨、印星生扶与身旺叠加、七杀有根而印未稳、羊刃待制泄等受阻候选。不是完整强度模型。
- 单一五合不自动抹去生克作用，多方争合进入待辨；没有合化裁决时不改五行。
- 120 项调候候选顺序和原注释保留；展示透出、暗藏、未见、根气与例外。六维分别记录扶抑、格局、调候、病药、通关、变格的依据和限制。
- 每步运追加到原局后，比较制化链支持、受扰和新增受阻状态；只列新增关系，不把原局内部关系重复算成岁运新增。
- 流年以真实立春时刻为边界，交运年按起止时刻拆段。成年主题从十八岁生日开始。测试包含非空感情窗口，避免空集合也“通过年龄验证”。
- 事业窗口检查运层引动、月柱或岁运链、流年相关十神透根；感情检查原局配偶星、日支、运层主题和流年透根或合身。只算条件观察期，不断具体事件已经发生。
- 四领域采用相应十神透藏、根气、月令、制化与宫位关系区分结论。相似结构仍可有相似建议，不随机改写制造“每个人都不同”。
- 紫微仅补充真实本命相关宫位、主星、亮度和本命四化；缺失不放示例，不冒用大限或流年四化。

## 仍属条件性实现，不宣称穷尽

- 旺衰并非完整司令分野算法：没有逐日人元司令、墓库开闭强度、复杂合冲刑害的力量衰减模型。得令、透藏、根气是定性代理条件。
- 成格判断尚未穷尽八格、兼格的所有成败救应变体；当前识别的是上述配合是否符合本轮条件。母多灭子、严格拔根等不强判。
- 普通、从势、专旺、化气有独立候选与反证，但特殊格局不作最终认证，也不无条件反转喜忌。
- 调候数据来自已安装 yueyuan v1.8 的参考表，原表自身标注待核对。已登记若干顺序/注释冲突；不是已完成逐条古籍校勘。
- 地支半合半会在既有关系图中作为结构提示；本地制化状态不把它们当完整会局。两层展示规则尚未完全合并到同一关系数据源。
- 紫微与八字不作“共同证实”的自动裁决，紫微动态大限/流年盘未在此模块补全。
- 真太阳时仍受城市经度、均时差近似和出生资料影响；全球历史时区、夏令时不在本轮修复范围。

## 验证与来源

执行 `pnpm run typecheck`、`pnpm test`、`git diff --check`。新增测试位于 `tests/local-analysis.test.mjs`，覆盖离线生成/渲染、输入隔离、月令取格、调候表、格局反例、交运和成年日期。

测试验证程序是否按规则运行，不验证命理对人生预测的准确率。本轮没有调用收费模型，没有发送出生资料至外部模型，没有做浏览器点击或视觉验收。

规则参考：已安装 yueyuan 的 SKILL、规则约束、patterns、biange、tiaohou-notes、analysis-checklist；调候表改编自 mingli_rules.py，许可见 `docs/licenses/yueyuan-MIT.txt`。本地条件化实现与原始资料不完全相同，以代码和本覆盖表为准。
