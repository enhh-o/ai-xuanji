# 出生奇门首版：口径、来源与验收

2026-09-12。用户确认先按出生时间排盘，事件时间起局后续增加。本轮仅本地开发，不提交推送或部署。

## 交付范围

- 八字、紫微、奇门三个入口同步切换命盘与分析；八字的大运区只在八字页显示。
- 出生奇门九宫可点击，显示宫位方位、天/地盘干、门星神、天禽和中宫寄干；选中宫位的依据、门宫生克、符号含义与反思建议随真实布局变化。
- 紫微原有十二宫、三方和对宫交互保留；建议不再借用八字喜用神。
- 各体系聊天分别保存；切页取消未完成请求，旧回复不串页；重新提交出生资料清空旧历史。
- 沿用 lunar-javascript 1.7.7，未增加运行依赖。

## 算法约定

时家转盘，拆补（甲己符头定三元），节气用定气。出生信息视为中国标准时 UTC+8，标准时与节气时刻比较；经过既有城市经度及均时差校正的真太阳时取日/时干支。甲己符头支为子午卯酉取上元、寅申巳亥取中元、辰戌丑未取下元。冬至至芒种阳遁，夏至至大雪阴遁。

地盘按局数顺/逆布戊己庚辛壬癸丁丙乙；天盘和九星沿外圈整体旋转；值使按旬内时序在九宫顺/逆推，再转八门。中五寄坤二，天禽携中干随天芮转动；中宫不伪造第九门。八神固定采用值符、腾蛇、太阴、六合、白虎、玄武、九地、九天，阳顺阴逆。

奇门为23点子初换日；既有八字使用 lunar 八字 sect=2 日柱零点换日，两者在晚子时可能不同，页面明确说明。首版支持1900—2100年；未额外处理历史夏令时，也没有引入精确出生地坐标服务。

## 验证与限制

自动测试覆盖阳/阴盘、中宫寄干、甲遁、夏至交节、真太阳时与标准时分工、23点换日、非法日期、三元、宫位渲染和聊天体系隔离。独立复核另查1080种布局与9720个宫位解释的内部一致性。

本地浏览器检查覆盖三盘切换、九宫点击、重新排盘、手机390px、键盘切换、聊天历史隔离与恢复。浏览器聊天请求被测试回复拦截，不调用收费模型；真实模型回答质量尚未实测。

这些检查证明程序在声明口径下的行为与一致性，不证明命理预测准确。当前解释没有完整覆盖十干克应、旺衰、空亡、击刑、入墓、应期及多流派断局；不由出生局断具体事件必然发生。事件起局、问题取用与更完整规则为后续任务。
